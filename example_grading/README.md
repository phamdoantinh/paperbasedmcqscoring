# example_grading — Self-Contained Grading Demo

This folder provides a **zero-configuration** example of the grading module. It is self-contained: all required inputs (pre-scored answer sheets and answer key) are included. No model weights or image processing are needed.

---

## Contents

| File / Folder | Description |
| ----------------------------- | ---------------------------------------------------------- |
| `scored_sheets/`              | 9 pre-scored answer sheet JSON files (output of `scoring.py`) |
| `answer_key.json`             | Correct answers for exam sets `101`, `102`, `423`, `568`  |
| `run_grading.py`              | Self-contained grading script — no arguments required      |
| `expected_output.json`        | Pre-computed expected grading report for verification      |
| `grading_output.json`         | Generated by `run_grading.py` (created on first run)       |

---

## Quick Start

From the **project root** (or any directory), run:

```bash
python3 example_grading/run_grading.py
```

No arguments. No configuration. The script automatically reads `scored_sheets/` and `answer_key.json` from the same folder.

## Input Format

### `scored_sheets/*.json`

Each file is a JSON object produced by `scoring.py` representing one student's answer sheet:

```json
{
  "examClassCode": "150099",
  "studentCode":   "20192681",
  "testSetCode":   "101",
  "answers": [
    { "questionNo": 1, "selectedAnswers": "D" },
    { "questionNo": 2, "selectedAnswers": "B" },
    ...
    { "questionNo": 60, "selectedAnswers": "" }
  ]
}
```

### `answer_key.json`

Maps each exam set code to an array of 60 correct answers:

```json
{
  "exam_name":       "Midterm Examination",
  "subject":         "Introduction to Computer Science",
  "total_questions": 60,
  "total_score":     10.0,
  "keys": {
    "101": ["D", "B", "B", "A", "D", "B", "B", "B", "C", "A", ...],
    "568": ["AC", "ACD", "AB", "BD", "", "B", "A", "", "BD", "AC", ...]
  }
}
```

> **Answer format:** `"A"` (single), `"AB"` / `"BCD"` (multi-answer), `""` (intentionally blank in key). Letter order does not matter — `"BA"` equals `"AB"`.

---

## Scoring Rule

A question earns full mark **only if the student's answer exactly matches the key** (after normalisation). Any other answer — wrong, incomplete, or blank — scores 0.

| Student answer | Key   | Result                 |
| -------------- | ----- | ---------------------- |
| `ABD`          | `ABD` | ✅ Correct — full mark |
| `AB`           | `ABD` | ❌ Incorrect — 0 pts   |
| `` (blank)     | `ABD` | ❌ Incorrect — 0 pts   |
| `` (blank)     | ``    | ✅ Correct — full mark |

## Relationship to the Full Pipeline

This demo shows **Step 2** of the full pipeline in isolation:

```
[Step 1]  scoring.py        → processes answer sheet images → scored_sheets/*.json
[Step 2]  run_grading.py    → grades scored sheets against answer key → report
```

The `scored_sheets/` in this folder are the actual output of `scoring.py` run on the sample images in `images/demo1/`. To reproduce Step 1 as well, see [`REPRODUCE.md`](../REPRODUCE.md).
